Yomi, hi-fi

A reading instrument. Warm paper ground, one vermilion accent reserved for the current place and the single primary action, an old-style serif for titles because the product's subject would be printed, and hairline rules instead of boxes so a list of thirteen chapters reads as a ledger.

Every colour resolves to a token in tokens.css. There are no colour literals in any stylesheet here or in any markup file, which is what makes a token-level contrast check meaningful.

What the visual system is doing

The accent has exactly two jobs. It marks where you are — the current nav item, the current tab, a spine on the section you are reading — and it fills the one primary button on a view. Nowhere else. When an accent appears on everything, it stops meaning anything, and here it would compete with the cover art.

The reader's chrome is dark in both themes. That is the one place the system deliberately ignores the operating system. Page artwork is the only bright thing on screen while reading, and a chrome that flipped with the theme would compete with it. The page itself keeps its paper in both themes for the same reason: a page of artwork does not invert.

Figures are set in tabular mono. Page counts, chapter numbers, and progress are compared vertically, so they are aligned and scannable. A number inside a sentence stays in the sans, because a number in prose should not announce itself.

Lists are ruled, not boxed. A card appears only where the card itself is the interaction. Thirteen chapters get a hairline and a fixed number column, so a 240-page omnibus and a 19-page chapter line up on the same axis.

One asymmetric move. The catalog grid's first card spans two columns at 72rem and up, because the first cover is the LCP element (NFR-PERF-001) and it should have the largest box on the page. Below 72rem the override is dropped entirely: an asymmetric grid at 320px is a broken grid.

Try it

  • The theme button in the header cycles system, light, dark. It is one attribute: every colour is a light-dark() pair.
  • Narrow the window on the reader and watch the chrome move from a bottom bar, to a right rail, to a rail plus a top bar.
  • Turn on reduced motion in your system settings. Nothing is lost: no information in this set is carried by motion.
  • Turn on Windows High Contrast. Borders return, fills are replaced with system colours, and nothing disappears.
