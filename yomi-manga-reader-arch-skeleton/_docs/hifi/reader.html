Direction is behaviour, not a mirror

reader-behavior.md §4

Direction decides which physical page is logical page 1, which key means next, which swipe means next, which tap zone means next, and how a spread pairs. Flipping the direction therefore reorders the column, swaps the arrow keys, moves the tap zones, and reverses the spread — and it leaves the physical page number exactly where it was.
