Wireframe: Sign in

Route /auth/signin · Tier 1, structure only · Source PRD FR-AUTH-003, ACCESSIBILITY.md §5 and §6

Grayscale blocks and region labels only. No colour, type, or scale decision is made at this tier.

Annotations

  • Every input has a visible label (ACCESSIBILITY.md §5). Placeholder text is not a label.
  • Errors are linked by aria-describedby and announced, and an error summary sits at the top of the form, linked and focusable (ACCESSIBILITY.md §5, NFR-A11Y-003). A bare red border is not an error announcement.
  • No colour-only signalling. An invalid field carries an icon and text as well as a border (NFR-A11Y-008).
  • Password has a labelled reveal toggle and its policy is announced through aria-describedby. The field does not block paste.
  • Rate limiting is a real state (INT-AUTH-003 rejects the 11th attempt in a minute). It is shown as a message with a retry time, not as a generic failure.
  • Signed out, the reader still has a reader. Anonymous reading is a supported journey (J-1); signing in is offered, never demanded.
