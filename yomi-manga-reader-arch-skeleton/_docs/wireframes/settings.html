Wireframe: Settings (reader preferences)

Route /settings · Tier 1, structure only · Source reader-behavior.md §16, ACCESSIBILITY.md §2 and §5

Grayscale blocks and region labels only. No colour, type, or scale decision is made at this tier.

Annotations

  • The reader preference form is a form, per reader-behavior.md §16 and ACCESSIBILITY.md §5.
  • Radio groups get a fieldset and legend (ACCESSIBILITY.md §2): default mode, direction override, and auto-advance are each a group, not a select of unexplained options.
  • Each control states its effect, not only its name. "Applied when a chapter opens; you can still switch per session" is the sentence that prevents the question.
  • Zoom default is a range 100–400% (§16) — a different control type from the radio groups, with the same quick-set values the reader chrome offers.
  • Changes persist with a 500ms debounce and take effect immediately for mode and direction, or on next open for the defaults (§16).
  • Nothing here is account-wide by accident. Preferences never leak between users: server-stored when signed in, device-local and profile-namespaced when not (§16).
