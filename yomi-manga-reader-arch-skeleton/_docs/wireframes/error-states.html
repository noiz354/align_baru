Wireframe: Error boundary / not found / empty state

Route src/app/error.tsx · src/app/not-found.tsx · Tier 1, structure only · Source ACCESSIBILITY.md §6, EC-RDR-02/08, EC-SE-02, EC-ADM-01

Grayscale blocks and region labels only. No colour, type, or scale decision is made at this tier.

Annotations

  • Every error page has three things (ACCESSIBILITY.md §6): the human cause, what the reader can do about it, and a link home. A page with a status code and nothing else is a defect.
  • Error pages take focus on entry and are announced (NFR-A11Y-003), so a screen-reader user is not left wherever the previous focus happened to be.
  • Typed causes are mapped to sentences, never shown as codes. The code belongs in a disclosure for the operator, not in the headline.
  • Permission is not a sign-in redirect (admin-workflow.md §1): a signed-in non-admin gets a 403 page, because sending them to a login form they already passed is a dead end.
  • Empty states carry the next action (ACCESSIBILITY.md §6) and a blank main never ships.
