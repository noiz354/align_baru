Wireframe: Search

Route /search · Tier 1, structure only · Source PRD FR-SEARCH-*, EC-SE-01…04, ACCESSIBILITY.md §5 and §6

Grayscale blocks and region labels only. No colour, type, or scale decision is made at this tier.

Annotations

  • Search is type="search", visibly labelled, and debounced — but the debounce must never drop rapid typing: the last input always wins, and Enter forces an immediate search (ACCESSIBILITY.md §5, FR-SEARCH-005).
  • Zero results is its own state, not an error and not a blank list (ACCESSIBILITY.md §6).
  • Empty catalog is a different state from no results (EC-SE-02): "The catalog is empty — content is added by the curator", never "no results for this query".
  • CJK titles and 1–2 character queries fall back to a prefix path (EC-SE-01, EC-SE-04). The result list states which path matched, so the ranking is not mysterious.
  • No result row is a link to nothing. If a card would have no destination, the card is not a link.
