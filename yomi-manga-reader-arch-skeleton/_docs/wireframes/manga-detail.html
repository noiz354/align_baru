Annotations

  • Breadcrumbs are required on detail and chapter pages (ACCESSIBILITY.md §4): Home / {title} / Chapter N.
  • One h1, and it is the manga title. Section headings are h2 and the chapter list is a list of items, so heading levels never skip (ACCESSIBILITY.md §2).
  • The chapter list is a real ol with li children inside a nav landmark. It is not a stack of divs with roles bolted on.
  • Every field in FR-CATALOG-006 is present: title, aliases, status, creators with roles, genres, synopsis, latest chapter. Reading direction is shown to readers as a plain label, not as a control — only an admin changes it.
  • Draft and unpublished chapters appear for admins only (J-4 step 5). This page is the reader view; the admin view adds publish controls, shown at tier 3.
  • Unread state is not a colour. A chapter carries an icon and the word "unread" alongside any count (NFR-A11Y-008).
