Grayscale blocks and region labels only. No colour, type, or scale decision is made at this tier.

Annotations

  • Admin pages are private and dense, never dark-patterned. State is always visible, because the curator must never have to guess whether an action landed, and the audit log is the appeal path (admin-workflow.md §10).
  • Every destructive action is behind a confirmation dialog with a focus trap (admin-workflow.md §10). That is UX protection, not security — the API is the security boundary, and the confirmation says so rather than implying it enforces anything.
  • Publish requires at least one page (admin-workflow.md §4). The control explains that, instead of failing later with a code.
  • The last-admin guard disables the control and explains (EC-ADM-04): a disabled button with a reason beside it, not a 409 after the click.
  • Delete states what is kept. A soft delete hides the title and keeps every reader's progress, library entry, and history (EC-ADM-02). A curator needs to know that before confirming, or they will not press the button for a one-off mistake.
