Wireframe: Bookmarks

Route /bookmarks · Tier 1, structure only · Source PRD FR-LIBRARY-*, EC-RDR-06

Grayscale blocks and region labels only. No colour, type, or scale decision is made at this tier.

Annotations

  • A bookmark is an explicit jump to a specific page (T-LIB-008), which is the one documented exception to saved-position-wins (EC-RDR-06): the intent was the specific page, so the deep link wins.
  • Each bookmark carries an optional note. Editing it happens in a dialog, so the reader keys are inert and focus is trapped while it is open (§9).
  • Grouped by series, not a flat reverse-chronological list — a reader bookmarks moments, then looks for them by title.
  • Delete asks first, and the confirmation names the page being removed, because that is the only way to be sure the right one is going.
