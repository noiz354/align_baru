Grayscale blocks and region labels only. No colour, type, or scale decision is made at this tier.

Annotations

  • What this tier is. Layout and information hierarchy only. Every block is a gray box with a region label. There is no palette, no type scale, and no illustration, because deciding those is tier 2's job.
  • Landmark contract. Every page below carries a skip link as the first focusable element, a <header> with a labelled <nav>, exactly one <main id="main">, and a <footer>. That is the structure AppShell.tsx (T-FOUND-004) owes the product.
  • Keyboard paths. Wherever this tier draws a tap zone or a swipe arrow it also draws the focusable button equivalent. Tap zones are input enhancement (reader-behavior.md §7.1), so a zone with no button beside it is a defect.
  • 320px floor. Every layout below collapses to one column at 320px with no fixed widths. Wide tables sit in a scroll container rather than forcing the page sideways.
