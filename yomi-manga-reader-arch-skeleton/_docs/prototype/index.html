Yomi, prototype

Four fidelity tiers exist because each answers a different question. The wireframe answers "is the structure right". The lo-fi answers "are the proportions and density believable". The hi-fi answers "does this look designed, in both themes, at the contrast floor". This tier answers the only question the other three cannot: does it actually work.

What is faithful here, and what is not

Faithful. The reader's state record and its invariants. The direction rules: reading order, arrow keys, swipes, tap zones, spread pairing, and the indicator computed from the reading-order position rather than the physical page. The mode and direction transition table, including the rule that crossing into or out of double resets the zoom. The keyboard map, with the browser's own zoom left alone and the reader keys made inert while a dialog is open. The swipe commit threshold and its cancel. The three completion variants. The per-page image failure with one automatic retry and two bounded manual attempts. Initial focus, and a live region that announces every tenth page in a long scroll rather than every page.

Simplified, and it is worth saying why. Pages are synthetic blocks, because this product only ever holds licensed content and a prototype has no licence. There is no server, so progress is written to this device and the status badge is not a promise about sync. Fullscreen uses the standard request with a notice if the browser refuses, and the pseudo-fullscreen fallback for browsers without the API is described rather than faked. Nothing here is wired to a route, so "back" is a link rather than a history entry.

The property that matters. Turn the tap zones off, ignore the swipes, and never touch a pointer. The reader is still completely operable, and every screen is still reachable by keyboard alone. Zones and swipes sit on top of a complete set of visible controls; they are not a substitute for them.

Try these first

  • Press M four times, then D, then watch the indicator. That sequence is where a reader implementation usually breaks.
  • Press End, wait a second, then Space to cancel the auto-advance. Do it twice to reach the third completion variant.
  • Narrow the window below 640px and below 1024px and watch the reader's chrome move.
  • Set the zoom to 300% and then switch mode twice. The zoom resets at the double boundary, and the page you were on does not move.
