Settings

The four reader preferences from reader-behavior.md §16. They are written to this device. Mode and direction take effect the next time a chapter opens, and also change immediately if you are already reading, because the reader and this page share one record.

Default reading mode

Applied when a chapter opens. You can still switch mode per session from the reader chrome.

Direction override

Leave this on None to use each title's own direction. A right-to-left title read left to right is genuinely hard to follow, so this is for the exception rather than the rule.

Default zoom

Currently 100%. Zoom is a transform: it never changes which page you are on, and it resets to this value when you enter a new chapter or switch to or from double.
