# Product edge cases

Catalog: aliases collide, locale missing, zero chapters, hidden/unpublished parent, deleted work, cursor invalidated by edit. Reader: empty/one page; page index invalid; cover pairing; direction mismatches; 50/100/200/500 pages; unusual aspect ratio/huge dimensions; failed/expired assets; slow/partial/offline; rapid input; resize/orientation; browser memory eviction; user switches account; page/chapter withdrawn mid-session. State: progress from another tab/device, same timestamp, stale page after reordering, user deletion, anonymous state collision. Admin: revoked role mid-session, concurrent editor, duplicate upload/finalize, object partial success, invalid rights assertion, failed review. Accessibility: keyboard trap, reduced motion, screen reader virtual cursor and fullscreen exit. Every failure path must preserve privacy and avoid publishing unsafe content.
