# User journeys

**Guest discovery:** landing/discover → search/filter → manga detail → chapter list → reader. Preserve return path and clear unavailable status; no authentication prompt blocks legal public content.

**Resume reader:** sign in → library/history → choose work → restore progress → read → next chapter; progress errors do not prevent reading and disclose unsaved status.

**Tune reader:** enter chapter → choose vertical/single/double → confirm direction and layout → adjust zoom/fullscreen → keyboard/touch operate same outcome → preference applies later.

**Editor publication:** editor sign-in → draft metadata → attach authorized chapter assets via upload workflow → validation/review → explicit publish → public verification → audit review. Any validation or authorization failure remains unpublished.

**Operations incident:** alert → correlate request/trace without exposing identifiers → inspect service/DB/storage health → apply runbook/rollback → restore only with approval → post-incident action items.
