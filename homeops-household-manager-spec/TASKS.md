# TASKS.md — Implementation Task Register

> 2026-09-26 · Status: **REGISTERED, NONE IMPLEMENTED**
> **Every task in this file is `NOT PART OF CURRENT PHASE`.** The architecture/skeleton phase forbids implementation (AGENTS.md §1). This register exists so that the first implementation slice can begin without re-deciding anything.
> Requirement mapping: docs/TRACEABILITY.md · Slice plan: ROADMAP.md · Decisions: ADR.md, DECISIONS.md.

## 0. How to use this file

1. An agent picks **one** task ID. It reads the fields below, then PRD.md (requirement), the ADR(s), the design doc, and the module's skeleton.
2. It expands the compact entry into the full template (shown in §2) inside the PR description.
3. It converts the matching `describe.todo` skeletons in `tests/**` into real tests.
4. It runs `node scripts/verify-docs.mjs`, typecheck, lint, and the focused tests.
5. It does **not** implement anything the task does not name.

### ID conventions

`T-<AREA>-<NNN>` where AREA ∈ {HH, MEM, AUTH, ROOM, CHORE, TRASH, RES, SHOP, MNT, ISSUE, ALERT, NOTIF, DASH, ACT, SET, TIME, PLAT, OBS, SEC, PRIV, A11Y, PERF, PWA, QA, DOC}.
Legacy aliases (1:1): `T-RESOURCE-NNN` ≡ `T-RES-NNN`; `T-MAINTENANCE-NNN` ≡ `T-MNT-NNN`. (See DECISIONS.md 2026-09-26.)
IDs are permanent: never renumber, never reuse. A cancelled task is marked `CANCELLED` with a date and a reason.

### Field glossary (compact entries)

| Field | Meaning |
| --- | --- |
| **Req** | Requirement IDs from PRD.md |
| **ADR** | Architecture decision record(s) that constrain the work |
| **Slice** | Vertical slice (ROADMAP.md) that owns the task |
| **Depends** | Tasks that must exist first |
| **Module** | Expected code home (ARCHITECTURE.md §9) |
| **Cases** | Edge cases the implementation must handle (each becomes a test where testable) |
| **Security** | Boundary/role/idempotency/validation note; `none beyond membership` means standard context + role checks apply |
| **Tests** | Which skeleton files/tiers must become real |
| **Docs** | Design/product doc that defines behaviour |
